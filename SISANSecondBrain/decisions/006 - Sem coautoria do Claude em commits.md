# 006 — Sem Claude como coautor em commits

**Contexto:** convenção já usada pelo usuário no Confia, Momentum e
Polymata.

**Decisão:** mensagens de commit deste projeto nunca incluem `Co-Authored-By:
Claude` nem qualquer menção ao Claude.

**Motivo:** consistência com os demais projetos do usuário — confirmado
explicitamente para este projeto em 17/09/2026.

**Não fazer:** não usar a atribuição padrão do Claude Code em commits ou PRs
deste repositório, mesmo que a orientação padrão da ferramenta sugira o
contrário.
