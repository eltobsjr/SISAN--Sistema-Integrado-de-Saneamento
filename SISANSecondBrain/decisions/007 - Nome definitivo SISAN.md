# 007 — Nome definitivo: SISAN

**Contexto:** `decisions/001` registrou "SIGESAN" como nome provisório,
pendente de validação. Apresentadas opções em 3 estilos (sigla técnica tipo
SIGAU, nome memorável/curto, nome ligado à marca do edital).

**Decisão:** o nome definitivo do projeto é **SISAN** — Sistema Integrado de
Saneamento.

**Motivo:** mantém a legibilidade institucional da família "SIG" sem herdar
o "ESAN" mais estranho de pronunciar do nome provisório; curto o bastante
pra caber em ícone de app e ser dito de cabeça no pitch.

**Impacto:** pasta do projeto renomeada de `sigesan/` para `sisan/`, vault
`SIGESANSecondBrain/` para `SISANSecondBrain/`, memória do Claude Code
movida para `~/.claude/projects/-home-eltobsjr-dev-pessoal-sisan/`. Todas as
menções a "SIGESAN"/"sigesan" substituídas por "SISAN"/"sisan" em toda a
documentação existente.

**Não fazer:** não usar mais "SIGESAN" em nenhum lugar novo. `decisions/001`
fica preservada como registro histórico (arquivo renomeado com sufixo
`(superseded)`), não apagada.
